High Entropy Alloys Analysis Repository

A modernized static webpage for the HEA Python code collection — now ready to view in any browser with polished sections, references, and usage guidance.

Overview

This repository contains a collection of Python scripts for High Entropy Alloy (HEA) analysis. It supports defect modeling, generalized stacking fault energy, dislocation analysis, short-range order, Monte Carlo simulation, and machine learning workflows.

The code base includes research-focused tools for BCC screw dislocations, SQS generation, atomic mismatch analysis, ML regression, and ML-based potential preparation.

Publication: https://doi.org/10.1016/j.commatsci.2024.113196

Repository Highlights

Defect & Dislocation Analysis

  • GSFE computations and screw dislocation models for BCC crystals.
  • Dislocation core energy extraction and analysis.
  • Tools for dislocation generation and Atomman-based diagnostics.

Structure Generation

  • Random SQS generation for BCC/FCC/HCP lattices.
  • Convert MCSQS/ATAT outputs into VASP POSCAR format.
  • Analyze local lattice distortions from VASP initial/final data.

Monte Carlo & Statistical Tools

  • Monte Carlo sampling for low-energy alloy structures.
  • Short-range order evaluation with pyscal.
  • Phase diagram utilities and configuration entropy calculations.

Machine Learning & Regression

  • Deep neural networks using TensorFlow and Keras.
  • Linear regression and ML data analysis tools.
  • Support for experimental HEA ML potentials from ternary to quinary systems.

Scripts Included

  • Calculate GSFE and screw dislocation properties for BCC crystals with generated POSCARs ready for VASP relaxation.
  • Analyze local lattice distortion and atomic mismatch using VASP POSCAR and CONTCAR files.
  • Generate random alloy structures using modified SQS algorithms.
  • Convert MCSQS ATAT output files into VASP POSCAR format.
  • Run Monte Carlo simulations for structure generation and energy minimization.
  • Use pyscal to detect short-range ordering and ordering tendencies.
  • Compute screw dislocation core energy and related metrics.
  • Build and test machine learning models for HEA property prediction.

GSFE = (E_fault - E_perfect) / Area
