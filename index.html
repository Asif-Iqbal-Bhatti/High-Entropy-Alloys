High Entropy Alloys Analysis Repository

A modern overview of Python-based workflows for HEA property analysis, structure generation, dislocation modeling, short-range order, and machine-learning research.

Repository Overview

This project contains a curated collection of Python scripts for analyzing properties of High Entropy Alloys (HEAs). The toolkit spans defect modeling, generalized stacking fault energy, dislocation analysis, short-range order, and machine learning workflows for HEA predictions.

It also includes experimental support for ML-based interatomic potentials spanning ternary to quinary alloy compositions.

Key Script Categories

Dislocation & Defect Analysis

  • GSFE and screw dislocation modeling for BCC crystals
  • Dislocation core energy computation
  • Dislocation creation and analysis with Atomman tools

Structure Generation

  • SQS/random structure generation for BCC / FCC / HCP lattices
  • POSCAR conversion for MCSQS / ATAT outputs
  • Local lattice distortion and atomic mismatch analysis

Monte Carlo & Statistical Modeling

  • Monte Carlo simulations for energy-driven structure generation
  • Short-range order evaluation using pyscal
  • Phase diagram and configuration entropy calculations

Machine Learning & Regression

  • Deep Neural Networks with TensorFlow / Keras
  • Linear regression and ML analysis for HEA data
  • ML-based potential workflows and data preparation

Featured Workflows

  • Generate stacking fault energy and screw dislocation data using BCC crystal structures.
  • Analyze atomic drift and mismatch from VASP POSCAR / CONTCAR coordinates.
  • Convert MCSQS / ATAT outputs into VASP POSCAR format.
  • Compute short-range order metrics and identify ordering tendencies in alloy systems.
  • Construct and evaluate machine learning models for HEA property prediction.
